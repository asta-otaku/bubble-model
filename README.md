# Web Bubble Viewer

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Table of Contents

- [Getting Started](#getting-started)
- [Features](#features)


## Getting Started

### Prerequisites


First, install the dependencies: (I recommend using npm)

```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

Then, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```


## Features

- **Create and Share Messages with (or without) Media via the browser**: Send texts and files via a web based composer powered by TipTap.
- **Drag and Drop**: Easily drag and drop files into the composer.
- **View Messages**: View the message given the Message ID.
